# PVP Practice

A Fabric client mod for Minecraft Java 26.3.

## Current prototype

- Press **G** in a world to open the practice menu.
- Select VS AI, 1v1, 2v2, 3v3, or 4v4.
- Select a weapon preset: sword, axe, bow, or random.
- Select an AI difficulty: easy, normal, or hard.
- Korean and English menu translations are included.

**Important:** this is currently a menu prototype. The Start button reports that match simulation is not implemented yet. AI opponents, team spawning, combat rules, and match lifecycle are future work.

## Build

GitHub Actions builds the project with Java 25 and Gradle, then uploads the JAR as a workflow artifact.
